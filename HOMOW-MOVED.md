# HoMoW — отдельный репозиторий

Дальнейшая разработка клиента и сервера HoMoW перенесена в [reformoti/Hold-Monster-World](https://github.com/reformoti/Hold-Monster-World).

Онлайн-игра: https://homow.92-5-85-199.sslip.io/

VPS получает код из нового репозитория (`/var/www/homow`). Прежние база Neon, аккаунты, сессии, прогресс и публичный адрес сохранены. Ключи и пароли в GitHub не переносятся.

Совместимая автономная копия и переход из Steam остаются в Brukivka. Её файлы не удалены. Обновления онлайн-игры следует вносить в новый репозиторий; публикация коммита сама по себе не развёртывает его на VPS.

Перенос выполнен из версии 6.33.8, коммит fc4035594164af3544a98cff1ae7a6009ed9cf57; исходная история остаётся здесь.
