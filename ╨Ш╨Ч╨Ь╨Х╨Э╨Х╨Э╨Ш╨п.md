# Изменения в исправленной версии Brukivka

## 1. Сохранения (приоритет №1)
- Поля прогресса проверяются при загрузке: уровни улучшений, НМТ, статистика Legit Check, заказ, инвентарь и предложения рынка.
- Некорректные значения ограничиваются допустимыми диапазонами, неизвестные поля исключаются. Отрицательные деньги **не запрещены**.
- Сохранения старых версий переносятся автоматически.
- При сохранении создаётся резервная копия `brukivka_kos_v4_backup` в localStorage.
- Если основное сохранение испорчено, игра пытается восстановить его из резервной копии / старых версий. Повреждённая строка по возможности сохраняется как `brukivka_kos_v4_corrupt`.
- При невозможности записи на странице появляется предупреждение. При первом запуске после обновления очищенные данные записываются обратно в хранилище.

## 2. Рынок Telegram
- Обновление предложений стоит **250 UAH**.
- Повторное обновление доступно через **30 секунд**. Время сохраняется после перезагрузки страницы.

## 3. Перепродажа
- Только что купленную вещь можно продать через **60 секунд**. Показывается обратный отсчёт.
- Предметы, купленные до обновления проекта, можно продавать без ожидания.
- Прибыльность перепродажи сохранена — это часть игрового процесса.

## 4. Лазеры и адаптивность
- Простое изменение ширины окна в рамках **того же** режима (ПК или телефон) больше не пересоздаёт позиции лазеров.
- Переключение режима происходит при пересечении границы **760 px**. При переходе ПК ↔ телефон позиции пересоздаются.
- Как и раньше, во время самой игры лазеры перемещаются после успешной доставки или попадания в лазер.
- При изменении размеров окна бруківка корректно возвращается в стартовую зону.

## 5. Часы
- Часы телефона обновляются каждую секунду без перезапуска игры.

## Проверки
- Проверен синтаксис JavaScript (`node --check`).
- В браузерных проверках: чистая загрузка, повреждённые значения, отрицательный баланс, восстановление из резервной копии, миграция старого сохранения, запрет записи в localStorage, переход ПК ↔ телефон, изменение ширины в рамках режима, покупка и продажа, платное обновление рынка.

## Запуск
Откройте `index.html` в браузере. Для просмотра через локальный сервер можно использовать `python -m http.server` в папке с проектом. Перед установкой поверх вашей версии рекомендуется вручную сохранить резервную копию старого прогресса браузера.
